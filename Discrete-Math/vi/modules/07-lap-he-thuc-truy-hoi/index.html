MODULE 7 · Giáo trình 2016 §2.4.1 · Đề cương 2.4.1–2.4.2

Lập hệ thức truy hồi

Nhiều bài đếm phụ thuộc tham số n và khó có công thức trực tiếp nhưng dễ tìm liên hệ giữa kết quả ở n và các giá trị nhỏ hơn: đó là hệ thức truy hồi. Học cách lập hệ thức (module này) rồi giải nó (Module 8). Câu 2a đề 2017–2020 và câu 3b đề 2023–2024 đều là “lập hệ thức truy hồi cho xâu nhị phân”.

  • Định nghĩa: hệ thức truy hồi, điều kiện đầu, nghiệm
  • Bốn mô hình kinh điển: lãi kép, Fibonacci, mất thứ tự, C(n,k)
  • Lập truy hồi bằng “xét bit cuối”, “xét khối cuối”, phần bù
  • Kiểm chứng bằng đếm trực tiếp
PHẦN 1 · Nền tảng

Hệ thức truy hồi và bốn mô hình kinh điển

Hệ thức truy hồi
aₙ = f(aₙ₋₁, aₙ₋₂, …, aₙ₋ₖ) với n ≥ n₀, cùng k điều kiện đầu
  • aₙsố cấu hình cần đếm ứng với tham số n
  • điều kiện đầuk giá trị a₀…a_(k−1) hoặc a₁…aₖ để xác định duy nhất dãy
Mô hìnhHệ thứcĐầu
Lãi kép 11%Pₙ = 1,11·Pₙ₋₁P₀ = 10000
Thỏ Fibonaccifₙ = fₙ₋₁ + fₙ₋₂f₁ = f₂ = 1
Mất thứ tựDₙ = (n−1)(Dₙ₋₁ + Dₙ₋₂)D₁ = 0, D₂ = 1
Tổ hợpC(n,k) = C(n−1,k−1) + C(n−1,k)C(n,0) = C(n,n) = 1
📖 Giải thích cho người mới bắt đầu
Thay vì tìm công thức chung cho aₙ, ta chỉ cần biết “muốn có aₙ thì lấy các số trước đó ghép lại thế nào”. Giống việc leo cầu thang: đến bậc n phải đi từ bậc n−1 hoặc n−2.

Phương pháp: lập hệ thức

PHẦN 2 · Phương pháp

Quy trình năm bước

  1. Đặt aₙ rõ ràng (số xâu/số cách … có độ dài n).
  2. Phân loại cấu hình độ dài n theo phần cuối (bit cuối, khối cuối, hành động cuối).
  3. Mỗi loại quy về cấu hình nhỏ hơn: dùng quy tắc cộng.
  4. Viết hệ thức và tìm điều kiện đầu bằng đếm trực tiếp.
  5. Kiểm tra bằng vài giá trị đếm được.
PHẦN 2 · Phương pháp

Mẫu 1: xét bit cuối

Không chứa hai bit 1 liên tiếp
aₙ = aₙ₋₁ + aₙ₋₂, a₁ = 2, a₂ = 3
  1. Bit cuối là 0: ghép “0” vào xâu hợp lệ độ dài n−1 ⇒ aₙ₋₁.
  2. Bit cuối là 1: bit trước phải là 0 ⇒ ghép “01” vào xâu hợp lệ độ dài n−2 ⇒ aₙ₋₂.
PHẦN 2 · Phương pháp

Mẫu 2: phần bù

Chứa 3 bit 1 liên tiếp (đề thi)
aₙ = aₙ₋₁ + aₙ₋₂ + aₙ₋₃ + 2ⁿ⁻³, a₁ = a₂ = 0, a₃ = 1

Cách 1: bₙ = số xâu KHÔNG chứa 111; bₙ = bₙ₋₁ + bₙ₋₂ + bₙ₋₃ (kết thúc 0, 10, 110), b₁ = 2, b₂ = 4, b₃ = 7. aₙ = 2ⁿ − bₙ.

Cách 2 (trực tiếp): xâu chưa có 111 ở n−3 vị trí đầu rồi kết thúc bằng 0, 10, 110 (aₙ₋₁ + aₙ₋₂ + aₙ₋₃) hoặc n−3 bit đầu tùy ý kèm “111” (2ⁿ⁻³).

Đếm trực tiếp: a₄ = 3, a₅ = 8, a₆ = 20, a₇ = 47, a₈ = 107.

PHẦN 2 · Phương pháp

Mẫu 3: tính chẵn lẻ

Số chữ số lẻ (từ mã thập phân)
aₙ = 8aₙ₋₁ + 10ⁿ⁻¹, a₁ = 1 (số lẻ chữ số d)
  1. Gọi aₙ: xâu có số LẺ chữ số d; bₙ: số CHẴN chữ số d; aₙ + bₙ = 10ⁿ.
  2. Thêm ký tự cuối: là d (1 cách) đổi tính chẵn lẻ; khác d (9 cách) giữ nguyên.
  3. aₙ = 9aₙ₋₁ + bₙ₋₁ = 9aₙ₋₁ + (10ⁿ⁻¹ − aₙ₋₁) = 8aₙ₋₁ + 10ⁿ⁻¹.

Ví dụ có lời giải (câu hỏi thật)

  • Chứa 111
  • Không chứa 111
  • Từ mã lẻ chữ số

PHẦN 3 · Ví dụ

Ví dụ 1: chứa 111

Ví dụ 1 (2.2.1b)Hệ thức truy hồi cho số xâu nhị phân độ dài n chứa 3 số 1 liên tiếp; tính a₆.
  1. aₙ = aₙ₋₁ + aₙ₋₂ + aₙ₋₃ + 2ⁿ⁻³, a₃ = 1, a₁ = a₂ = 0.
  2. a₄ = 3, a₅ = 8, a₆ = 20 (đối chiếu đếm trực tiếp 64 xâu).
PHẦN 3 · Ví dụ

Ví dụ 2: không chứa 111

Ví dụ 2 (2.2.20a)an là số xâu nhị phân độ dài n KHÔNG chứa ba số 1 liên tiếp. Tìm hệ thức và a₇.
  1. aₙ = aₙ₋₁ + aₙ₋₂ + aₙ₋₃, a₁ = 2, a₂ = 4, a₃ = 7.
  2. a₄ = 13, a₅ = 24, a₆ = 44, a₇ = 81.
PHẦN 3 · Ví dụ

Ví dụ 3: từ mã lẻ chữ số 6

Ví dụ 3 (2.1.17b)Từ mã hợp lệ là xâu chữ số thập phân chứa một số LẺ chữ số 6; aₙ là số từ mã độ dài n. Tìm hệ thức và điều kiện đầu.
  1. aₙ = 8aₙ₋₁ + 10ⁿ⁻¹.
  2. a₁ = 1 (chỉ xâu “6”).
  3. a₂ = 18, a₃ = 244, a₄ = 2952, a₅ = 33616.
PHẦN 3 · Ví dụ

Ví dụ 4: hệ thức không thuần nhất bậc 1

Ví dụ 4 (2.2.17a, lặp)aₙ = aₙ₋₁ + 2n với a₀ = 1. Giải bằng phương pháp lặp.
  1. aₙ = a₀ + Σ_{i=1..n} 2i = 1 + n(n+1).
  2. Kiểm tra: a₃ = 1 + 12 = 13 và 1 → 3 → 7 → 13.

PHẦN 4 · Bẫy và mở rộng

Năm bẫy thường gặp

  • Quên điều kiện đầu hoặc cho thiếu (hệ thức bậc k cần k điều kiện).
  • Đếm trùng khi phân loại theo bit cuối chưa loại trừ đủ.
  • Chẵn lẻ: nhớ aₙ + bₙ = tổng số xâu.
  • Đề gốc có lỗi chép: ngân hàng 2.2.2b ghi “xâu thập phân … Tính số xâu nhị phân” — đề bài nhầm, ta hiểu là xâu thập phân.
  • Tính a_n bằng hệ thức phải khớp đếm trực tiếp ở n nhỏ; luôn kiểm tra.
PHẦN 4 · Bẫy và mở rộng

Mở rộng: k bất kỳ

Tổng quát: xâu nhị phân không có k bit 1 liên tiếp: aₙ = aₙ₋₁ + … + aₙ₋ₖ, aⱼ = 2ʲ (j < k), aₖ = 2ᵏ − 1. Xâu có ít nhất một dãy k bit 1: bₙ = bₙ₋₁ + … + bₙ₋ₖ + 2ⁿ⁻ᵏ, bⱼ = 0 (j < k), bₖ = 1 (đã kiểm chứng bằng liệt kê với k = 2, 3, 4).

PHẦN 5 · Ứng dụng và ôn tập

Case study: quy hoạch động

Bậc thang: đi n bậc, mỗi bước 1 hoặc 2 bậc: aₙ = aₙ₋₁ + aₙ₋₂ (Fibonacci). Trong lập trình động, hệ thức truy hồi là “công thức chuyển trạng thái”; giải bằng bảng hoặc đệ quy có nhớ.

PHẦN 5 · Ứng dụng và ôn tập

Tổng kết

  • Phân loại theo phần cuối, dùng quy tắc cộng.
  • Tìm điều kiện đầu, kiểm tra bằng đếm trực tiếp.
Tiếp theoModule 8: giải hệ thức truy hồi tuyến tính thuần nhất.

1. Nội dung chi tiết

Hệ thức truy hồi cho phép tính mọi số hạng từ vài số hạng đầu, và rất hợp với lập trình. Giáo trình 2016 §2.4.1 dùng bốn mô hình: lãi kép, thỏ Fibonacci, số mất thứ tự Dₙ = (n−1)(Dₙ₋₁ + Dₙ₋₂), và hệ số tổ hợp C(n,k) = C(n−1,k−1) + C(n−1,k).

2. Ví dụ chi tiết có lời giải

Ví dụ · 1. Lãi kép

Gửi 10000 USD, lãi 11%/năm: Pₙ = 1,11Pₙ₋₁, P₀ = 10000 ⇒ Pₙ = 10000·1,11ⁿ; sau 30 năm P₃₀ ≈ 228 922,97 USD.

Ví dụ · 2. Số mất thứ tự

D₁ = 0, D₂ = 1, D₃ = 2, D₄ = 9, D₅ = 44, D₆ = 265, D₇ = 1854 (theo Dₙ = (n−1)(Dₙ₋₁ + Dₙ₋₂)).

Ví dụ · 3. Xâu chứa số chẵn bit 0 (2.2.18a)

aₙ = 2aₙ₋₁, a₁ = 1 ⇒ a₆ = 32.

Ví dụ · 4. Lương tăng (bài tập giáo trình)

Lương năm n sau 1987: aₙ = 1,05aₙ₋₁ + 1000, a₀ = 50000; a₈ ≈ 83.422 USD (công thức tường minh aₙ = 70000·1,05ⁿ − 20000).

Ví dụ · 5. Máy bán tem (bài tập giáo trình)

Đồng 1 USD, tờ 1 USD, tờ 5 USD, thứ tự quan trọng: aₙ = 2aₙ₋₁ + aₙ₋₅, a₀ = 1. a₁₀ = 1217 (a₀…a₁₀ = 1, 2, 4, 8, 16, 33, 68, 140, 288, 592, 1217; tính bằng chương trình).

5. Case study

Số cách xếp gạch domino 2×1 lát kín hình chữ nhật 2×n thỏa aₙ = aₙ₋₁ + aₙ₋₂ (a₁ = 1, a₂ = 2). Chương trình tính bằng bảng chỉ O(n), thay vì đệ quy ngây thơ O(φⁿ).
