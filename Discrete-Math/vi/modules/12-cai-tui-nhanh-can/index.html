Duyệt toàn bộ và nhánh cận: bài toán cái túi

Bài toán tối ưu tổ hợp: trong tập hữu hạn D các phương án, tìm phương án làm hàm mục tiêu f lớn nhất (hoặc nhỏ nhất). Hai thuật toán của TRR1: duyệt toàn bộ (đúng nhưng chậm) và nhánh cận (đúng và cắt bớt nhánh). Câu 5 của mọi đề PTIT là bài cái túi: 2017–2020 dùng duyệt toàn bộ, 2023–2024 dùng nhánh cận.

  • Mô hình cái túi và duyệt toàn bộ
  • Cận trên g và nguyên tắc cắt nhánh
  • Chạy thuật toán nhánh cận từng bước
  • Cái túi biến nguyên (ví dụ giáo trình)
PHẦN 1 · Nền tảng

Mô hình cái túi

Bài toán cái túi 0/1
f(x) = Σ cⱼxⱼ → max; Σ aⱼxⱼ ≤ b; xⱼ ∈ {0,1}
  • cⱼgiá trị của vật j
  • aⱼtrọng lượng của vật j
  • bsức chứa của túi

Tập phương án D = {x ∈ {0,1}ⁿ : Σ aⱼxⱼ ≤ b}; có tối đa 2ⁿ vectơ để kiểm tra.

PHẦN 1 · Nền tảng

Thuật toán duyệt toàn bộ

Bước 1: XOPT = ∅;  FOPT = −∞  (max)   hoặc +∞ (min)
Bước 2: for each X ∈ D {
           S = f(X);
           if (FOPT < S) { FOPT = S; XOPT = X; }
        }
Bước 3: return (XOPT, FOPT)
Nhược điểmSố phương án bùng nổ: 15! ≈ 1,3·10¹² hoán vị cần hơn 36 giờ (giáo trình). Với cái túi 2ⁿ: n = 50 đã cần hơn một triệu giây ở tốc độ 10⁹ phép/giây.

PHẦN 2 · Phương pháp

Hàm cận g

Cận trên của phương án bộ phận
g(u₁,…,u_k) = δ_k + c_{k+1}·b_k / a_{k+1}
  • δ_kgiá trị các vật đã chọn (c₁u₁ + … + c_ku_k)
  • b_ktrọng lượng còn lại của túi
  • c_{k+1}/a_{k+1}tỉ số giá trị/trọng lượng lớn nhất trong các vật còn lại
Vì sao là cận trênSắp các vật theo c/a giảm dần (c₁/a₁ ≥ c₂/a₂ ≥ …). Bài toán biến liên tục (cho phép lấy phân số vật) có phương án tối ưu là dồn toàn bộ phần còn lại vào vật có c/a lớn nhất: giá trị ≥ giá trị nguyên. Nên g ≥ mọi phương án mở rộng.

Đây là “ước lượng lạc quan”: nếu ngay cả ước lượng lạc quan nhất của một nhánh cũng không hơn kỷ lục đang có thì không cần xem nhánh đó.
PHẦN 2 · Phương pháp

Thuật toán nhánh cận (giáo trình hình 4.4)

  1. Sắp xếp các vật theo cⱼ/aⱼ giảm dần (giữ thứ tự chỉ số khi bằng nhau).
  2. FOPT = −∞. Quay lui: với vật thứ k, thử xₖ = 1 trước (nếu còn đủ chỗ), rồi xₖ = 0.
  3. Tại nút bộ phận tính δ, w (trọng lượng còn lại), g.
  4. Nếu k = n: cập nhật FOPT nếu δ > FOPT.
  5. Nếu k < n: chỉ mở rộng khi g > FOPT; ngược lại cắt nhánh.
#include <bits/stdc++.h>
using namespace std;
int n, b; int c[20], a[20], x[20], xopt[20]; int fopt = -1;
void Try(int i, int delta, int rem){      // đã gán x[1..i-1]
    int t = min(1, rem / a[i]);
    for(int v = t; v >= 0; v--){
        x[i] = v; int d2 = delta + c[i]*v, r2 = rem - a[i]*v;
        if(i == n){ if(d2 > fopt){ fopt = d2; copy(x+1, x+n+1, xopt+1); } }
        else {
            double g = d2 + (double)c[i+1] * r2 / a[i+1];   // cận trên
            if(g > fopt) Try(i + 1, d2, r2);                // cắt nhánh nếu g <= FOPT
        }
    }
}
int main(){
    cin >> n >> b;
    vector<int> cc(n), aa(n), id(n);
    for(int i = 0; i < n; i++) cin >> cc[i];
    for(int i = 0; i < n; i++) cin >> aa[i];
    iota(id.begin(), id.end(), 0);
    sort(id.begin(), id.end(), [&](int p, int q){ return (long long)cc[p]*aa[q] > (long long)cc[q]*aa[p]; }); // c/a giảm dần
    for(int i = 1; i <= n; i++){ c[i] = cc[id[i-1]]; a[i] = aa[id[i-1]]; }
    Try(1, 0, b);
    cout << "f* = " << fopt << "\n";
}

Ví dụ 1: ví dụ giáo trình

Ví dụ giáo trình 2016 (số lượng không hạn chế)10x₁ + 5x₂ + 3x₃ + 6x₄ → max; 5x₁ + 3x₂ + 2x₃ + 4x₄ ≤ 8; xⱼ nguyên không âm.
Sắp xếp theo c/a giảm dần: x₁ (10/5 = 2.00), x₂ (5/3 = 1.67), x₃ (3/2 = 1.50), x₄ (6/4 = 1.50).
Ký hiệu nút: (x…) | δ = giá trị đã chọn | w = trọng lượng còn lại | g = δ + c_{k+1}·w/a_{k+1}.
Lưu ý: có tỉ số c/a bằng nhau; giữ thứ tự theo chỉ số biến (kết quả tối ưu không đổi).
Gốc: FOPT = −∞, g = 16.
(1) | δ = 10, w = 3, g = 15 → mở rộng (g > FOPT)
(1, 1) | δ = 15, w = 0, g = 15 → mở rộng (g > FOPT)
(1, 1, 0) | δ = 15, w = 0, g = 15 → mở rộng (g > FOPT)
(1, 1, 0, 0) | δ = 15, w = 0, g = 15 ★ cập nhật kỷ lục
(1, 0) | δ = 10, w = 3, g = 29/2 ≈ 14.50 ✗ cắt (g ≤ FOPT)
(0) | δ = 0, w = 8, g = 40/3 ≈ 13.33 ✗ cắt (g ≤ FOPT)
Kết quả: f* = 15, x* = (1, 1, 0, 0) (theo thứ tự biến gốc x₁…x_4).

Đối chiếu giáo trình: g gốc = 16, nút (1): g = 15, (1,0): g = 14,5 bị cắt, (0): g = 40/3 bị cắt; kết quả f* = 15. (Giáo trình in x* = (1,1,0,1) do lỗi trích; phương án hợp lệ là (1,1,0,0).)

PHẦN 4 · Bẫy và mở rộng

Năm bẫy thường gặp

  • Quên sắp theo c/a ⇒ cận sai, có thể cắt nhầm nhánh chứa nghiệm.
  • Cắt nhầm dấu: cắt khi g ≤ FOPT, mở rộng khi g > FOPT.
  • Cập nhật kỷ lục chỉ tại lá (k = n).
  • Lấy bằng nhau c/a: giữ thứ tự chỉ số; kết quả tối ưu vẫn đúng.
  • Khi trình bày: ghi rõ (x…), δ, w, g ở mỗi nút và nêu nút bị loại.
PHẦN 4 · Bẫy và mở rộng

Mở rộng: so sánh với quy hoạch động

Nhánh cận trong trường hợp xấu nhất vẫn là O(2ⁿ) (không cắt được nhánh nào), nhưng với cận tốt thường giải được n hàng chục đến hàng trăm. Quy hoạch động cho cái túi 0/1 chạy O(n·b) giả đa thức, phù hợp khi b nhỏ.

1. Nội dung chi tiết

Nhánh cận là quay lui có kiểm tra cận. Giáo trình 2016 chứng minh mệnh đề: với c₁/a₁ ≥ … ≥ cₙ/aₙ, phương án tối ưu của bài toán biến liên tục là x₁ = b/a₁, còn lại 0, giá trị c₁b/a₁; từ đó suy ra cận g cho phương án bộ phận.
