MODULE 8 · Giáo trình 2016 §2.4.2 · Đề cương 2.4.3

Giải hệ thức truy hồi

Đến đây ta giải hệ thức truy hồi tuyến tính thuần nhất hệ số hằng: aₙ = c₁aₙ₋₁ + … + c_kaₙ₋ₖ. Kỹ thuật là tìm nghiệm dạng rⁿ, dẫn tới phương trình đặc trưng. Câu 2b của mọi đề 2017–2020 và câu 3a của đề 2023–2024 đều thuộc dạng này (bậc 2 nghiệm kép: aₙ = −14aₙ₋₁ − 49aₙ₋₂).

  • Phương trình đặc trưng
  • Hai nghiệm phân biệt, nghiệm kép
  • Bậc 3 và nghiệm bội
  • Tìm hệ số từ điều kiện đầu, kiểm tra
PHẦN 1 · Nền tảng

Phương trình đặc trưng

Phương trình đặc trưng
aₙ = c₁aₙ₋₁ + … + c_kaₙ₋ₖ ⇒ r^k − c₁r^(k−1) − … − c_k = 0
  • rnghiệm đặc trưng: aₙ = rⁿ là nghiệm ⇔ r thỏa phương trình này
  • bậc kcần k điều kiện đầu
Ví dụaₙ = aₙ₋₁ + 2aₙ₋₂ ⇒ r² − r − 2 = 0 ⇒ r = 2, r = −1.
📖 Giải thích cho người mới bắt đầu
Thử nghiệm dạng aₙ = rⁿ vào hệ thức, chia cả hai vế cho r^(n−k) sẽ được đa thức theo r. Mọi nghiệm r của đa thức đều cho một nghiệm rⁿ.

PHẦN 2 · Phương pháp

Ba dạng nghiệm

Định lý 1: hai nghiệm phân biệt r₁ ≠ r₂
aₙ = α·r₁ⁿ + β·r₂ⁿ
Định lý 2: nghiệm kép r₀
aₙ = (α + β·n)·r₀ⁿ
Nghiệm bội m
(α₀ + α₁n + … + α_(m−1)n^(m−1))·rⁿ

Bậc k tổng quát: cộng các phần đóng góp của từng nghiệm, được đúng k hằng số; giải hệ k ẩn từ k điều kiện đầu.

PHẦN 2 · Phương pháp

Quy trình giải

  1. Viết phương trình đặc trưng, tìm mọi nghiệm (kể cả bội).
  2. Viết dạng nghiệm tổng quát với hằng số α, β, …
  3. Thay n = 0, 1, … vào điều kiện đầu, giải hệ.
  4. Kiểm tra: tính a₂, a₃ bằng hệ thức và bằng công thức, phải khớp.
PHẦN 2 · Phương pháp

Ghi chú phạm vi

Nghiệm phức: nếu phương trình đặc trưng có nghiệm phức thì dùng dạng lượng giác (Định lý 3 của giáo trình); phần này không thuộc yêu cầu thi TRR1. Đề thi PTIT chỉ dùng nghiệm thực (nguyên).

Không thuần nhất bậc 1: aₙ = aₙ₋₁ + f(n) giải bằng phương pháp lặp: aₙ = a₀ + Σᵢ f(i).

PHẦN 3 · Ví dụ

Ví dụ 1: nghiệm kép

Ví dụ 1 (đề 2017–2020, câu 2b)aₙ = −14aₙ₋₁ − 49aₙ₋₂, n ≥ 2, a₀ = 3, a₁ = 35.
  1. r² + 14r + 49 = 0 ⇔ (r + 7)² = 0 ⇒ nghiệm kép r = −7.
  2. aₙ = (α + βn)(−7)ⁿ. a₀ = α = 3; a₁ = (3 + β)(−7) = 35 ⇒ β = −8.
  3. aₙ = 3·(-7)ⁿ − 8·n·(-7)ⁿ. Kiểm tra a₂ = −14·35 − 49·3 = −637 = (3 − 16)·49 ✓.
PHẦN 3 · Ví dụ

Ví dụ 2: hai nghiệm phân biệt

Ví dụ 2 (2.2.1a)aₙ = −aₙ₋₁ + 6aₙ₋₂, a₀ = 1, a₁ = 5.
  1. r² + r − 6 = 0 ⇒ r = 2, r = −3.
  2. α + β = 1; 2α − 3β = 5 ⇒ α = 8/5, β = −3/5.
  3. aₙ = −(3/5)·(-3)ⁿ + (8/5)·2ⁿ. (a₂ = −5 + 6 = 1; công thức: (8/5)·4 − (3/5)·9 = 32/5 − 27/5 = 1 ✓.)
PHẦN 3 · Ví dụ

Ví dụ 3: bậc 3 ba nghiệm

Ví dụ 3 (2.1.16a)aₙ = 2aₙ₋₁ + aₙ₋₂ − 2aₙ₋₃, n ≥ 3, a₀ = 3, a₁ = 6, a₂ = 0.
  1. r³ − 2r² − r + 2 = 0 ⇔ (r − 2)(r − 1)(r + 1) = 0.
  2. aₙ = α·2ⁿ + β·1ⁿ + γ·(−1)ⁿ.
  3. Giải hệ ba ẩn: aₙ = −2·(-1)ⁿ + 6 − 2ⁿ.
PHẦN 3 · Ví dụ

Ví dụ 4: bậc 3 (đề trắc nghiệm)

Ví dụ 4 (đề ôn trắc nghiệm)aₙ₊₃ = 14aₙ₊₂ − 59aₙ₊₁ + 70aₙ, a₀ = −7, a₁ = −20, a₂ = −100.
  1. r³ − 14r² + 59r − 70 = 0 ⇔ (r − 2)(r − 5)(r − 7) = 0.
  2. aₙ = −7·2ⁿ + 3·5ⁿ − 3·7ⁿ. Kiểm tra a₃ = 14(−100) − 59(−20) + 70(−7) = −710 và công thức: −56 + 375 − 1029 = −710 ✓.

PHẦN 4 · Bẫy và mở rộng

Năm bẫy thường gặp

  • Dấu của phương trình đặc trưng: aₙ = 6aₙ₋₁ − 9aₙ₋₂ ⇒ r² − 6r + 9 = 0. Giáo trình 2016 ví dụ 3 chép nhầm thành r² − 6r − 9 = 0; đúng là (r − 3)² = 0.
  • Nghiệm kép phải có nhân tử n: (α + βn)rⁿ.
  • Nghiệm âm: ghi (−7)ⁿ có ngoặc.
  • Thiếu điều kiện đầu: đề 2.2.26a chỉ cho aₙ = 14aₙ₋₁ − 49aₙ₋₂; chỉ có dạng tổng quát (α + βn)7ⁿ.
  • Kiểm tra: so a₂, a₃ tính từ hệ thức và từ công thức.
PHẦN 4 · Bẫy và mở rộng

Mở rộng: công thức Binet

Fibonacci: fₙ = fₙ₋₁ + fₙ₋₂, f₀ = 0, f₁ = 1. r² − r − 1 = 0 ⇒ r = (1 ± √5)/2. fₙ = (1/√5)[((1+√5)/2)ⁿ − ((1−√5)/2)ⁿ] (công thức Binet).

Sơ đồ minh họa

Quy trình giải hệ thức truy hồi · mở file draw.io nguồn

1. Nội dung chi tiết

Nếu r là nghiệm của r² = c₁r + c₂ thì aₙ = rⁿ thỏa aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ vì c₁rⁿ⁻¹ + c₂rⁿ⁻² = rⁿ⁻²(c₁r + c₂) = rⁿ. Tổ hợp tuyến tính của nghiệm cũng là nghiệm; với hai nghiệm phân biệt, hai điều kiện đầu xác định α, β duy nhất (định thức Vandermonde khác 0).

2. Ví dụ chi tiết có lời giải

Ví dụ · 1. Giáo trình (ví dụ 1)

aₙ = aₙ₋₁ + 2aₙ₋₂, a₀ = 2, a₁ = 7: r = 2, −1; α + β = 2, 2α − β = 7 ⇒ α = 3, β = −1: aₙ = 3·2ⁿ − (−1)ⁿ.

Ví dụ · 2. Nghiệm kép (giáo trình, ví dụ 3, đã sửa dấu)

aₙ = 6aₙ₋₁ − 9aₙ₋₂, a₀ = 1, a₁ = 6: r = 3 kép; α = 1, 3(1 + β) = 6 ⇒ β = 1: aₙ = (1 + n)3ⁿ.

Ví dụ · 3. Bậc 2 khác

aₙ = 5aₙ₋₁ − 6aₙ₋₂, a₀ = 3, a₁ = 8: r = 2, 3; α + β = 3, 2α + 3β = 8 ⇒ β = 2, α = 1: aₙ = 2ⁿ + 2·3ⁿ. Kiểm tra a₂ = 40 − 18 = 22 và 4 + 18 = 22 ✓.

Ví dụ · 4. Hệ thức không thuần nhất bậc 1 (2.2.22a)

aₙ = aₙ₋₁ + 2n + 3, a₀ = 4: aₙ = 4 + n(n+1) + 3n = n² + 4n + 4 = (n + 2)².

Ví dụ · 5. Bài tập giáo trình 14

(b) aₙ = 7aₙ₋₁ − 6aₙ₋₂, a₀ = 2, a₁ = 1: r = 1, 6: aₙ = 11/5 − (1/5)6ⁿ. (d) aₙ = 2aₙ₋₁ − aₙ₋₂, a₀ = 4, a₁ = 1: (r − 1)² = 0: aₙ = 4 − 3n.

4. Bối cảnh lý thuyết và lịch sử

📜 Nguồn gốcCông thức tường minh của Fibonacci được Jacques Binet (1843) công bố, nhưng đã được Euler và de Moivre biết từ thế kỷ 18. Phương pháp nghiệm đặc trưng tương tự phương pháp giải phương trình vi phân tuyến tính hệ số hằng.

5. Case study

Độ phức tạp T(n) = T(n−1) + T(n−2) + 1 của Fibonacci đệ quy có nghiệm cỡ φⁿ ≈ 1,618ⁿ: với n = 50 cần cỡ 10¹⁰ lời gọi, còn phương pháp lặp chỉ 50 phép cộng.
