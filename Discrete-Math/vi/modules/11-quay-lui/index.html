MODULE 11 · Giáo trình 2016 §3.4 · Đề cương 3.3

Quay lui

Quay lui (backtracking) xây cấu hình từng thành phần: chọn giá trị cho x₁, rồi x₂, …; khi gặp ngõ cụt (vi phạm điều kiện) thì quay lại thay lựa chọn trước đó. Đó là cách liệt kê khi cấu hình có ràng buộc, và là nền của nhánh cận ở Module 12.

  • Khung Try(i) và cây tìm kiếm
  • Điều kiện chấp nhận và cắt nhánh
  • Quay lui cho xâu nhị phân, hoán vị, tổ hợp
  • Đếm số lời gọi, so với phương pháp sinh
PHẦN 1 · Nền tảng

Khung thuật toán quay lui

void Try(int i){
    for (mỗi ứng viên v của x[i]) {
        if (chấp nhận v) {
            x[i] = v;  <ghi nhớ trạng thái>;
            if (i == n) <ghi nhận nghiệm>;
            else Try(i + 1);
            <hoàn trả trạng thái>;    // quay lui
        }
    }
}
// gọi Try(1)
Năm bước1) duyệt ứng viên; 2) kiểm tra chấp nhận; 3) gán và ghi nhớ; 4) nếu đủ thì ghi nhận, ngược lại đệ quy; 5) hoàn trả (bỏ đánh dấu used, giảm tổng…).

Giống đi trong mê cung: đến ngã rẽ chọn một hướng; nếu bế tắc thì quay lại ngã rẽ gần nhất và thử hướng khác. Việc “quay lại” do lời gọi đệ quy trả về.

PHẦN 2 · Phương pháp

Quay lui: xâu nhị phân

Xâu nhị phân độ dài n (2ⁿ nghiệm):

#include <bits/stdc++.h>
using namespace std;
int n, x[32];
void Try(int i){
    for(int v = 0; v <= 1; v++){
        x[i] = v;
        if(i == n){ for(int j = 1; j <= n; j++) cout << x[j]; cout << "\n"; }
        else Try(i + 1);
    }
}
int main(){ cin >> n; Try(1); }
PHẦN 2 · Phương pháp

Quay lui: hoán vị

Hoán vị (dùng mảng used để đảm bảo khác nhau):

#include <bits/stdc++.h>
using namespace std;
int n, x[20]; bool used[20];
void Try(int i){
    for(int v = 1; v <= n; v++) if(!used[v]){
        x[i] = v; used[v] = true;                       // chọn v
        if(i == n){ for(int j = 1; j <= n; j++) cout << x[j] << " "; cout << "\n"; }
        else Try(i + 1);
        used[v] = false;                                // hoàn trả trạng thái
    }
}
int main(){ cin >> n; Try(1); }
PHẦN 2 · Phương pháp

Quay lui: tổ hợp

Tổ hợp chập k (cận trên n − k + i cắt sớm các nhánh không đủ phần tử):

#include <bits/stdc++.h>
using namespace std;
int n, k, x[20];
void Try(int i){
    for(int v = x[i-1] + 1; v <= n - k + i; v++){
        x[i] = v;
        if(i == k){ for(int j = 1; j <= k; j++) cout << x[j] << " "; cout << "\n"; }
        else Try(i + 1);
    }
}
int main(){ cin >> n >> k; x[0] = 0; Try(1); }

PHẦN 3 · Ví dụ

Ví dụ 1: hoán vị n = 3

Ví dụ 1 (3.3a, kiểm nghiệm n = 3)Thuật toán quay lui hoán vị của 1,2,3.

Thứ tự in: 123, 132, 213, 231, 312, 321 (trùng thứ tự từ điển vì thử v tăng dần).

Số lần gọi Try: Try(1) 1 lần, Try(2) 3 lần, Try(3) 6 lần: tổng 10 lời gọi (n! = 6 nghiệm in ra).

PHẦN 3 · Ví dụ

Ví dụ 2: tổ hợp n = 5, k = 3

Ví dụ 2 (3.6a, n = 5, k = 3)Tổ hợp chập 3 của {1..5} bằng quay lui.

(1,2,3), (1,2,4), (1,2,5), (1,3,4), (1,3,5), (1,4,5), (2,3,4), (2,3,5), (2,4,5), (3,4,5) — 10 tổ hợp.

PHẦN 3 · Ví dụ

Ví dụ 3: tập con K phần tử có tổng S

Ví dụ 3 (slide PTIT, Exercise 10)Liệt kê mọi X ∈ {0,1}ⁿ có Σxᵢ = K và Σaᵢxᵢ = S.
  1. Try(i, cnt, sum): với v = 0, 1: cnt′ = cnt + v; sum′ = sum + aᵢ·v.
  2. Cắt nhánh nếu cnt′ > K, hoặc sum′ > S, hoặc cnt′ + (n − i) < K.
  3. Khi i = n: in nếu cnt′ = K và sum′ = S.
PHẦN 3 · Ví dụ

Ví dụ 4: N quân hậu

Ví dụ 4: 4 quân hậuĐặt 4 quân hậu lên bàn cờ 4×4 không ăn nhau.

Quay lui theo từng hàng, thử cột 1..4, loại cột và hai đường chéo bị chiếm. Có 2 nghiệm (theo cột ở mỗi hàng): (2,4,1,3) và (3,1,4,2). Với n = 8 có 92 nghiệm.

PHẦN 4 · Bẫy và mở rộng

Năm bẫy thường gặp

  • Quên hoàn trả used[v] = false sau lời gọi đệ quy ⇒ mất nghiệm.
  • Sai cận của vòng lặp (tổ hợp: n − k + i).
  • Không cắt nhánh ⇒ thành vét cạn.
  • Nhầm sinh và quay lui: sinh cần hàm kế tiếp; quay lui cần đệ quy.
  • In sai chỉ số: x[1..n] hay x[0..n−1].
PHẦN 4 · Bẫy và mở rộng

Mở rộng: số lời gọi

Số lời gọi Try khi liệt kê hoán vị của n phần tử: Σ_{i=1..n} n!/(n − i + 1)!; với n = 8 là 69.281 (chỉ hơn n! = 40 320 một chút), còn nhánh cận/cắt tỉa giúp giảm mạnh khi có ràng buộc.

Sơ đồ minh họa

Cây quay lui xâu nhị phân n = 3 · mở file draw.io nguồn

1. Nội dung chi tiết

Cây tìm kiếm quay lui có nút là phương án bộ phận (x₁,…,x_k); lá là phương án đầy đủ. Quay lui duyệt cây theo chiều sâu; cắt nhánh khi phương án bộ phận không thể mở rộng thành nghiệm. Đây chính là cơ sở của thuật toán nhánh cận (giáo trình hình 4.2).

2. Ví dụ chi tiết có lời giải

Ví dụ · 1. Xâu nhị phân n = 3 (3.9a)

Thứ tự in: 000, 001, 010, 011, 100, 101, 110, 111. Try(1) gọi 1 lần, Try(2) 2 lần, Try(3) 4 lần: tổng 7 = 2³ − 1 lời gọi.

Ví dụ · 2. Xâu nhị phân không có hai bit 1 liền nhau

Điều kiện chấp nhận: nếu x[i−1] = 1 thì không cho x[i] = 1. Với n = 5 có 13 xâu (số Fibonacci F₇).

Ví dụ · 3. Tổng tập con

Tập {3, 5, 7, 9, 11}, tìm tập con có tổng 16: chỉ có {5, 11} và {7, 9} (đã kiểm chứng bằng liệt kê 31 tập con khác rỗng). Quay lui cắt nhánh ngay khi tổng đang chọn vượt 16.

Ví dụ · 4. Hoán vị không có điểm bất động (số mất thứ tự)

Điều kiện chấp nhận v ≠ i: D₄ = 9 hoán vị (Module 7).

Ví dụ · 5. Code đề thi 4a

Chương trình liệt kê hoán vị bằng quay lui (đề 2023–2024, câu 4a) là mẫu perm_bt ở trên; thêm phép nhập n từ bàn phím bằng cin >> n.
